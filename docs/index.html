A simple start.
A clear update path.

The first release will provide verified binaries, exact Linux requirements and installation instructions. Install Cubi, open a terminal in your project, and launch its workspace.

Update instructions will accompany the release. Package-manager installations will use their package manager for updates. macOS and Windows are future work, not current support claims.
