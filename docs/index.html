A home for your coding agents

Your project.
Your agents.
Their own workspace.

Cubi gives each project its own isolated environment for Claude Code, Codex and Pi, powered by NVIDIA OpenShell. Run cubi in a project folder and you get the same environment every time you come back.

In your project folder
$ cd your-project
$ cubi claude

Opens or reuses the project's environment and runs Claude Code in it.

Why use it

01 / FILES

Live project files

Your project is shared with the environment. Edits land in your host files immediately.

02 / ISOLATION

Confined agents

Agents run in a microVM by default, or a rootless Podman container, under OpenShell sandbox policy. Your host home, credentials and SSH agent are not shared.

03 / SETTINGS

Settings that persist

Development tools, agent settings and history stay in the environment between sessions.

04 / PROJECT

One environment per project

Multiple agents and Git worktrees for the same project share it.

05 / LIFECYCLE

Stop and start

Stop an environment to free resources and start it again later. Guest files are kept.

06 / SSH

SSH access

Connect a desktop agent over SSH with a generated alias and a pinned host key.

How it works

$ cubi        # open or reuse this project's environment
$ cubi codex  # run Codex in it
$ cubi pi     # run Pi in it
$ cubi info   # SSH host and guest folder
$ cubi stop   # stop it, keep its files
$ cubi start  # start it again

Host account credentials are not copied into the environment. Sign in to your agents inside it, or use your desktop client's supported flow.
